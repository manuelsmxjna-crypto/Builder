⚠ Sin aceleración GPU

El navegador no pudo usar WebGPU (la API de aceleración, no la tarjeta gráfica). El proceso de IA seguirá en CPU/WASM y puede tardar más.

En este celular se usa un modelo ligero (~5 MB) y CPU a propósito, para no cerrar Chrome.
Tener GPU en el PC no basta: hace falta Chrome/Edge actualizado y abrir BixStudio por http/https (no como archivo local).
